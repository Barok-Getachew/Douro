# Digital Menu Magic

Here is a strong prompt you can give to Claude, ChatGPT, Lovable, Bolt, or any AI website builder to create a professional digital menu.

Prompt:

Create a modern, premium, mobile-first digital menu website for D'ouro Soul Food restaurant in Salzburg, Austria.

Before designing, research the restaurant thoroughly using Google, including:

Google Business Profile

Official website (if available)

Google Reviews

Photos

Instagram

Facebook

Any other public information

Use the restaurant's branding, colors, atmosphere, cuisine, logo (if publicly available), and overall style to make the menu match the restaurant's identity.

Main Goal

The website should be designed specifically for customers who scan a QR code placed on restaurant tables.

There should be no app download and no login.

The QR code should open the menu instantly.

Design Requirements

Build a premium-looking website similar to restaurants in Dubai, London, and Michelin-style restaurants.

Produce:

Fully working digital menu ready for deployment on GitHub Pages, Vercel, or Netlify.

Ensure all restaurant information, menu items, prices, contact details, and social media links are accurate by using the latest publicly available information before generating the final website.

This prompt should produce a polished, restaurant-quality QR menu experience. After it's built, you can print the QR code and place it on each table so customers can instantly browse the menu from their phones.
